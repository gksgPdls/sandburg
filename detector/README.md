# detector — 의료 서류 위변조 탐지기

> 🚧 **개발 중입니다.** 구조와 판정 기준은 바뀔 수 있고, 아직 실제 심사에 쓸 수준이 아닙니다. 남은 일은 [아래](#개발-상태)에 있습니다.

서류 사진 한 장을 넣으면 **OpenRouter VLM 으로 문서 값을 읽고**, 그 값을 **로직 엔진**에 넣는 동시에 **이미지 픽셀 엔진**을 돌려
`위변조 의심 / 확인 필요 / 정상` 으로 판정하고, 어느 칸이 왜 걸렸는지 위치와 근거를 보여 줍니다.

```
                 ┌─ ① 문서 값 읽기 ── OpenRouter VLM (Qwen, 1회) ──→ 판독값 ──→ ② 로직 엔진 ─┐
서류 사진 ───────┤                                                    (공식 근거 규칙)        ├─→ ④ 판정 ──→ 웹 화면
                 └─ ③ 이미지 픽셀 엔진 (읽기와 상관없이 바로 시작) ─────────────────────────────┘    (등급형 OR)   근거 상자 · 확대 렌즈
                      (다시 그린 칸의 노이즈 · 경계 · 글자 모양)
```

| 단계 | 하는 일 | 코드 |
|---|---|---|
| ① 문서 값 읽기 | VLM 이 영수증 · 진단서의 칸(금액, 진료기간, 질병코드, 요양기관 종류 …)을 JSON 으로 옮겨 적음. 판단은 하지 않고 읽기만. 응답은 캐시해서 같은 사진은 다시 부르지 않음 | [`reader/`](reader/), [`pipeline/vlm_read.py`](pipeline/vlm_read.py) |
| ② 로직 엔진 | 읽은 값을 공식 근거와 대조 — A 서식 산식 · 열 합계, B 심평원 수가 · 본인부담률, C 상병마스터(없는 코드 · 성별 · 나이), D 날짜 · 번호 체계, F 보험금이 걸린 칸 | [`logic/`](logic/) · 기준: [`logic/규칙_적용기준.md`](logic/규칙_적용기준.md) |
| ③ 이미지 픽셀 엔진 | 같은 문서 안의 같은 종류 칸끼리 비교해 "다시 그린 칸"을 찾음 (매끈함 · 노이즈 · 글자 경계 · 색, 복사-붙여넣기) | [`pixel/`](pixel/) |
| ④ 판정 | 둘 중 하나라도 걸리면 잡고, 근거 세기로 등급을 나눔 | [`pipeline/decide.py`](pipeline/decide.py) |

판정 표 (등급형 OR):

| 로직 | 픽셀 | 판정 |
|---|---|---|
| 확정 · 강함 | 아무거나 | 위변조 의심 |
| 아무거나 | 정상 오탐 2% 기준 넘음 | 위변조 의심 |
| 참고 규칙 걸림 | 10% 기준 걸림 | 위변조 의심 |
| 참고 규칙 걸림 | 안 걸림 | 확인 필요 |
| 안 걸림 | 10% 기준 걸림 | 확인 필요 |
| 안 걸림 | 안 걸림 | 정상 |

## 실행

```bash
# 웹 화면: 사진을 올리면 판정 · 엔진별 결과 · 근거 칸 (http://localhost:8771)
.venv/bin/python -m detector.pipeline.web --demo <샘플 폴더> --실시간

# 폴더 · 평가셋 한 번에 (판정 · 답안 · 요약)
.venv/bin/python detector/pipeline/run.py <사진 폴더 또는 평가셋> --처음 10

# 엔진 하나만
.venv/bin/python -c "from detector.logic import inspect; print(inspect('영수증.jpg')['verdict'])"   # 로직 (로컬 OCR)
.venv/bin/python -m detector.pixel.web                                                              # 픽셀 웹 화면
```

## 폴더

| 폴더 | 하는 일 |
|---|---|
| `pipeline/` | 합친 탐지기 — 읽기 · 두 엔진 병렬 · 판정 · 웹 화면(`web/`) · 실행기(`run.py`) |
| `reader/` | OpenRouter VLM 판독기 · 호출 도구 · 실서류 전송 막기 |
| `logic/` | 로직 엔진 (단독으로는 로컬 OCR 로 읽음) |
| `pixel/` | 픽셀 엔진 v1(노이즈 · FFT · 픽셀 통계), v2(글자 · 픽셀 일관성, 카피무브) |
| `eval/` | 채점 · 답안 합치기, 평가셋 형식(`eval/evalsets/README.md`) |
