- 정상 97장은 세 평가셋이 같은 사진입니다 → 서로 다른 서류 97장 + 변조본 146장
- v3 · v4 · v3_1500 에는 AI 판독값(`판독값/판독값_동현_AI판단_v1.csv`)과 같은 실행의 동현 답안(`답안/답안_동현_AI판단_v1.csv`)이 들어 있어 `combine/run.py` 가 키 없이 돕니다

## 새 평가셋 만들기 (각자)

형식만 맞으면 합치기 실행기(`combine/run.py`) · 채점기(`eval/score_testset.py`)가 그대로 돕니다.

```
testsets/<새평가셋>/
  문제/                       사진 (예: T001.png — 이름에 정답이 드러나지 않게)
  문제목록.csv                 문제_id · 파일(예: 문제/T001.png) · 문서_종류(영수증 / 진단서) · 가로 · 세로
  정답_채점용/정답.csv          문제_id · 정답(정상 / 변조) · 문서_종류 · 방식 · 내용_모순 · 마스크
  정답_채점용/마스크/           바뀐 곳만 흰색(255)인 PNG. 정답.csv 의 마스크 칸은 '마스크/T001.png' 처럼 정답_채점용/ 기준 (정상은 비움)
```

- 방식 · 내용_모순 · 마스크는 **열만 있으면 되고 값은 비워도 됩니다** (있으면 방식별 점수 · 위치 적중까지 나옴)
- **정상 서류도 꼭 섞기** — 정상이 없으면 오탐을 잴 수 없음
- **합성 서류만.** 실서류 · 1차 변조본으로 만든 평가셋은 AI(외부)로 읽으면 안 됨 → 그런 평가셋은 혜인 님 엔진(로컬 OCR)으로만
- 처음 한 번: 키가 있는 사람이 `combine/run.py testsets/<새평가셋> --읽기 --합성서류만` (판독값 · 동현 답안이 평가셋에 저장됨) → 그 뒤로는 누구나 키 없이
