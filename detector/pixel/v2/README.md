# 탐지기 v2 — 글자·픽셀 일관성 (A 검사, 개발 중)

목표: 고도화 변조(v2 변조기)를 '위변조 의심'으로 잡으면서, 정상 문서 오탐을 v1(문서 오탐 70%)보다 크게 줄인다 (목표 10% 이하).
방식: 원본 없이, 칸 위치도 모른 채 문서 전체를 검사. 칸마다 특징을 재서 같은 문서의 같은 종류 칸(같은 열 금액, 같은 줄, 날짜)과 비교.

| 검사 | 보는 것 |
|---|---|
| A1 굵기·진하기 | 획 두께, 잉크 밝기, 종이와의 대비 |
| A2 자간 | 숫자 사이 틈, 쉼표 앞뒤 틈 (글자 높이로 나눔) |
| A3 높이·기준선 | 숫자 높이, 바닥선 (기울기 보정) |
| A4 획 테두리 | 가장자리 선명도, 글자 둘레 띠의 밝기·노이즈 |
| A5 흰 박스·칸 테두리 | 종이 결이 사라진 직사각형, 표 선 끊김 |
| A6 기울기 | 표 선 각도와 글자 줄 각도 차 |
| A7 카피앤무브 거르기 | 우연히 같은 픽셀로 잡힌 오탐 제외 (노이즈 상관) |
| A8 숫자·날짜 형식 | 쉼표 자리, 없는 날짜, 영수증번호 연월 |

검사는 `checks.py`의 CHECKS에 등록 → `detector/pixel/scripts/v2/evaluate.py`로 평가 (정탐·오탐·미탐, 위치 적중). A0 = v1 탐지기 기준선.
