위조 의심 칸확인 필요 칸정상 범위 (순위만)실제로 고친 칸 (정답)
판정은 3단계: 문서 점수(가장 높은 금액 칸 점수)가 넘으면 위조 의심, 넘으면 확인 필요, 아니면 정상. 기준값은 튜닝용 정상 문서에서 2% / 10%만 넘는 점수. · '잡음' = 위조 의심 + 확인 필요 · 위치 적중 = 잡은 것 중 가장 높은 칸이 실제 고친 칸 · AUC = 위조 문서 점수가 정상 문서보다 높을 확률 (0.5 = 못 가름) · 괄호 = 95% 신뢰구간 · 표의 행을 누르면 그 묶음만 봄 · A11은 금액 모양 칸만 봄 (날짜·전화번호·①② 번호·글자 섞인 칸 제외), 같은 문서에서 크기·굵기 비슷한 금액 칸끼리 비교.
