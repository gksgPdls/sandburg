# 로직 탐지기 규칙 적용 기준

2026-11-06 기준. 코드는 `rules.py`(A·B·C·D 규칙), `focus.py` + `data/focus_rules.yaml`(F 규칙, 보험 청구 핵심 칸)입니다.

## 원칙: 보수적으로 판정

**정상 서류를 위변조로 판정하는 것이 가장 나쁜 결과**입니다. 그래서 규칙을 두 등급으로 나눴습니다.

| 판정 | 언제 | 등급 |
|---|---|---|
| **위변조 의심** | 정상 서류에서는 나올 수 없는 모순 (서식에 인쇄된 산식, 번호 체계, 날짜 순서, 코드 체계) | 확정 · 강함 |
| **확인 필요** | 정상 서류도 어긋날 수 있거나, 공식 데이터가 다 갖춰지지 않은 규칙 | 참고 (화면에 "확인 필요인 이유"를 함께 표시) |

판독 오류 대책도 하나 있습니다. 규칙이 쓰는 칸 중 하나라도 두 OCR이 다르게 읽은 칸이면, 그 규칙 결과는 자동으로 "참고"로 내려갑니다.

## 1. 위변조 의심으로 판정하는 규칙 (적용)

| 규칙 | 내용 | 근거 | 정상 서류에서 안 깨지는 이유 |
|---|---|---|---|
| A1 ⑥⑦⑧ 산식 | ⑥ 진료비 총액 = ①+②+③+④, ⑦ 공단부담 총액 = ②+⑤, ⑧ 환자부담 총액 = (①-⑤)+③+④ | 요양급여규칙 별지 제6호서식 | 서식에 인쇄된 계산식 |
| A2 열 합계 | 항목 행을 열마다 더한 값 = 합계 칸 (③ 전액본인부담, ④ 비급여 등) | 같은 서식 | 합계의 정의 |
| A2 ①+② | 급여 합계(①+②) = 행별 본인부담금 + 공단부담금 합 | 같은 서식 | 합계의 정의 (절사가 있어도 ①+②는 그대로) |
| C1 | 진단일이 2021년 이후인데 상병마스터에 없는 코드 (U코드 제외) | 심평원 상병마스터 2025.9 (KCD-8) | 2021년부터 KCD-8 체계 |
| C2 | 적힌 병명이 다른 코드의 공식 병명과 거의 같음 (코드만 바꾼 흔적) | 상병마스터 | 병명 유사도 0.9 이상, 자기 코드와는 0.8 미만일 때만 |
| C3 성별 | 여성 전용 코드인데 남성 환자 (또는 그 반대) | 상병마스터 성별구분 | 의학적으로 불가능한 조합 |
| D1 | 미래 날짜 · 진료 시작이 끝보다 늦음 · 외래인데 발행일이 진료일보다 이름 · 진단서 날짜 순서(발병 ≤ 진단 ≤ 발급, 입원 ≤ 퇴원) | 날짜의 정의 | 시간 순서 |
| D3 검증번호 | 사업자등록번호 10번째 자리 검증번호 | 국세청 산식 | 모든 사업자번호가 지킴 |
| D4 생년월일 | 주민번호 앞자리가 없는 날짜이거나 진료일보다 늦음 | 날짜의 정의 | |
| F:CA-CIS | 코드는 C(악성)인데 조직검사 결과가 제자리암·경계성 | KCD 분류 체계 | 제자리암은 D0 계열 |

## 2. 확인 필요로만 알리는 규칙 (위변조 판정에서 뺌)

| 규칙 | 내용 | 확인 필요로 낮춘 이유 |
|---|---|---|
| A1 ⑩ | 납부할 금액 = ⑧-⑨ | 실제 영수증에는 감면·할인·미수금 줄이 따로 있음 |
| A1 ⑪ | 납부한 금액 = 카드+현금영수증+현금 | 계좌이체·포인트·미수금 등 다른 수납 방법 줄이 있음 |
| A2 ① 절사 | ① 본인부담금 합계 = 행 합 (외래 100원 미만 절사) | 병원마다 반올림·10원 절사 방식이 다르고 65세 이상 정액제 같은 예외가 있음. 허용값에 반올림과 10원 단위 처리도 추가함 |
| A3 | 납부한 금액 > 납부할 금액 | 선수금·예치금·과오납 환불 |
| B1 | 행별 본인부담률 (외래 30·35·40·45·50·60%, 입원 20%, 식대 50%, 병실 20·30·40%) | 선별급여(50·80·90%), 65세 이상 정액제, 6세 미만 경감, 산정특례 부담률이 아직 데이터에 없음 |
| B2 | 진찰료가 진료일 연도·종별 공식 단가로 나올 수 있는 금액인지 | 6세 미만 소아 가산, 상급종합 진찰료, 진찰료 칸에 다른 기본진료료를 합쳐 적는 양식이 아직 데이터에 없음 |
| B4 | 입원료 = 일수 × 간호등급별 단가 | 장기입원 체감(16일 이상 90%, 31일 이상 85%), 간호간병통합서비스, 소아 가산, 외박 일수 미반영 |
| B6 | 공휴일 표시인데 평일 · 토요 가산 금액인데 토요일이 아님 · 공휴일인데 가산 없음 | 임시공휴일, 가산 표시 방식이 병원마다 다름. **토요일은 아예 보지 않음** (토요일 오후는 공휴 가산 표시 가능) |
| C1 (2021년 이전 · U코드) | 마스터에 없는 코드 | 예전 진단은 그때 KCD 버전 코드를 썼을 수 있고, U코드는 기관별 사용이 다름 |
| C3 나이 | 연령 제한 코드 | 심사 경고 성격 (예: 노안 40세 이상) |
| C4 | 주상병으로 못 쓰는 코드 · 같은 코드 두 번 | 주상병 사용구분은 청구 심사 기준이고, 좌우 구분으로 같은 코드를 두 번 쓰기도 함 |
| D1 (입원) | 발행일이 진료기간 끝보다 이름 | 입원 중간 정산 영수증 |
| D1 (외래) | 외래인데 진료기간이 하루가 아님 | 묶음 발행 |
| D2 | 영수증번호 앞 날짜·연월이 진료일·발행일과 다름 | 영수증번호 체계가 EMR마다 다르고, 재발행·후일 수납이면 날짜가 다름 |
| D3 세무서 | 사업자번호 앞 3자리 ≠ 주소 관할 세무서 | 병원 이전, 세무서 신설·분할 |
| D4 검증번호 | 주민번호 13번째 자리 | 번호 변경자, 외국인등록번호 |
| F:BURN-DEPTH | 화상 깊이 글자와 코드 4번째 자리 | 여러 부위에 깊이가 다른 화상이 함께 있을 수 있음 |
| F:FX-KIND | 골절 코드인데 소견이 염좌 (또는 반대) | 골절 의증, 다른 부위 골절, 부상병 염좌 |
| F:CA-DATE | 진단 연월일 ≠ 조직검사 결과보고일 | 결과를 설명한 날을 진단일로 적는 병원이 있음 |
| F:ADM-OPINION | 입퇴원 칸 날짜 ≠ 소견의 입퇴원 날짜 | 소견의 날짜가 이전 입원이나 다른 병원을 가리킬 수 있음 |
| 나머지 F 규칙 | `focus_rules.yaml`에서 원래 참고 등급 | |

## 3. 아예 검사하지 않는 것

| 항목 | 이유 |
|---|---|
| 요양기관 종류 체크 칸 (의원·병원·종합병원) | 사진에서 자주 잘못 읽어서(실사진 원본 32%) 규칙에 쓰지 않음. 그래서 종별만 바꾼 조작은 못 잡음 |
| 검사료·주사료·처치료 등 묶음 행 금액 | 여러 수가 항목의 합이라 영수증만으로는 단가를 확인할 수 없음 (상세 내역서가 필요) |
| 상급종합병원 진찰료 | 단가표에 없음 |
| 공휴일 목록이 없는 해 (2024년 이전, 2027년 이후) | 판단 불가로 건너뜀 |
| 규칙을 다 지킨 조작 (이름 바꾸기, 같은 해 안에서 날짜 옮기기, 맞는 코드와 병명을 통째로 교체) | 로직으로는 원리상 못 잡음. 이미지 엔진이 맡음 |

## 4. 이렇게 바꾸면서 잃은 것 (합성 시험 1,010건)

"위변조 의심"까지 가는 탐지율입니다. 괄호 안은 "확인 필요"까지 포함한 값입니다.

| 조작 | 바꾸기 전 | 바꾼 후 | 지금 잡는 규칙 |
|---|---|---|---|
| 합계 불일치 (항목 +1,000) | 100% | 100% | A2 |
| 자릿수 조작 (항목 ×10) | 100% | 100% | A2 |
| 사업자번호 숫자 1개 | 100% | 100% | D3 검증번호 |
| KCD 코드 교체 | 100% | 100% | C2 |
| 진단일 > 발급일 | 100% | 100% | D1 |
| **합계까지 맞춘 항목 +1,000** | 100% | **0% (100%)** | B1 → 확인 필요 |
| **진찰료 +1,000 (합계 맞춤)** | 98.6% | **0% (98.8%)** | B2 → 확인 필요 |
| **날짜 +7일 / +1일** | 99.8% / 100% | **0% (99.8% / 100%)** | D2 → 확인 필요 |
| **연도 -1** | 100% | **0% (100%)** | D2·B2 → 확인 필요 |

정리하면 다음과 같습니다.
- **합계까지 정교하게 맞춘 조작과 날짜 조작**은 이제 "위변조 의심"이 아니라 "확인 필요"(이유 포함)로 나옵니다. 놓치는 것은 아닙니다.
- 생성기 정상 서류 1,010건의 오탐은 바꾸기 전후 모두 0입니다.

### 휴대폰 사진 (변조데이터셋 675장)

| | 바꾸기 전 | 바꾼 후 |
|---|---|---|
| 영수증 정상 원본 오탐 (위변조 의심) | 31.3% (47/150) | **13.3% (20/150)** |
| 영수증 정상 원본, 확인 필요까지 포함 | 46.7% | 46.0% |
| 진단서 정상 원본 오탐 | 1.4% | 1.4% |
| 내용 조작 85장 위변조 의심 | 89.4% (76) | **41.2% (35)** |
| 내용 조작 85장, 확인 필요까지 포함 | — | 100% |

- **KCD 교체:** 21/21 그대로 잡힙니다.
- **숫자 조작·합계 깨기·EDMS:** 놓친 41장은 주로 B1 부담률, B2 진찰료, A3 납부액, A1 ⑩⑪로 잡던 것입니다. 이제는 "확인 필요"로 나옵니다.
- **남은 오탐 20장:** 판독 오류로 ⑥ 산식이나 열 합계가 깨진 경우입니다. 두 OCR이 같은 값으로 잘못 읽어서 "판독 불확실"로 걸러지지 않았습니다.

## 5. 다시 "위변조 의심"으로 올리는 조건

| 규칙 | 필요한 것 |
|---|---|
| B1 | 선별급여·정액제·6세 미만·산정특례 부담률을 데이터에 추가하고, 실제 병원 정상 서류에서 오탐 0 확인 |
| B2 | 소아 가산, 상급종합 진찰료, 기본진료료를 합쳐 적는 양식을 추가하고, 실제 서류로 확인 |
| D2 | EMR별 영수증번호 체계를 실제 서류로 확인 (날짜형 번호를 쓰는 EMR만 판정) |
| 공통 | 실제 병원 정상 서류로 오탐률을 재고, 0이 나온 규칙만 올림 |

**검토 중인 방법:** 서로 독립인 "확인 필요"가 두 개 이상 겹치면 위변조 의심으로 올리는 것입니다. 예를 들어 연도를 바꾸면 D2 영수증번호와 B2 진찰료 단가가 함께 어긋납니다. 실제 서류로 오탐을 재 본 뒤에 결정합니다.
