# add_text — 여백에 글자 추가

주 탐지 축: **글리프** · ID: `GL_xxx` · 스크립트: [`scripts/tamper_add_text.py`](../../scripts/tamper_add_text.py)

## 조작 방식

기존 내용을 지우지 않고 **빈칸이나 여백에 글자를 써 넣는다.** 예: 진단서 병명 칸에 진단 추가, 영수증 빈 행에 항목 추가. "정교해서 육안 탐지가 어렵다"고 알려진 실제 수법이다.

1. 추가할 문구를 정한다. 콘텐츠 로직에 걸리지 않도록 **내용이 앞뒤가 맞게** 고른다(KCD 코드와 병명 일치, 치료 내용과 모순 없음)
2. 원본 글자에 맞춘다

   | 항목 | 옵션 | 맞추는 방법 |
   |---|---|---|
   | 크기 | `--fit "기존문구" 폭` | 원본에 있는 문구를 같은 폰트로 그렸을 때 폭이 같아지는 크기를 자동으로 찾는다 |
   | 잉크 농도 | `--ink` | 사진 속 글자는 순검정이 아니다. 기존 문구를 옆에 시험 삼아 합성해 획 농도를 비교한다 |
   | 번짐 | `--blur` | 촬영·압축으로 뭉개진 정도 |
   | 기울기 | `--angle` | 표 괘선의 기울기를 재서 맞춘다 (반시계 +) |
   | 위치 | `--xy` | 기존 줄과 왼쪽 끝을 맞추고, 문서의 줄 간격만큼 아래 |

3. 흰 박스를 깔지 않고 잉크를 종이에 곱해 합성한다. 종이 질감이 글자 사이로 남는다

```bash
cd dataset
./.venv/bin/python scripts/tamper_add_text.py samples/add_text/GL_001_original.jpg \
    --text "추가할 문구" --xy X Y --fit "원본에 있는 문구" 폭 \
    --ink 20 --blur 0.5 --angle 0.5 \
    -o samples/add_text/GL_001_tampered.jpg --mask samples/add_text/GL_001_mask.png
```

## 탐지 원리

- **글리프:** 주력이자 거의 유일한 축이다. 추가한 줄의 자형·획 굵기·자간이 원본 줄과 어긋난다
- **copy-move:** 복사한 픽셀이 없어서 못 잡는다
- **콘텐츠 로직:** 내용을 맞게 고르면 못 잡는다

**난이도는 폰트 일치도로 조절한다.** 원본 폰트(굴림 계열로 추정)를 구하면 `--font`만 바꿔 어려운 변형을 만든다. 폰트까지 같으면 글리프 단서마저 줄어들어 탐지 공백 후보가 된다.

## 샘플

### GL_001 — 진단서 병명 추가

병명 칸의 `(D18.0) 혈관종` 아래 빈 줄에 **`(Q82.5) 선천성 비신생물성 모반`** 을 추가했다. 혈관 레이저 치료라는 기존 치료 의견과 앞뒤가 맞는 진단으로 골랐다.

| 항목 | 값 | 근거 |
|---|---|---|
| 폰트 | Apple SD Gothic Neo Regular | 원본 폰트를 구하지 못함 |
| 크기 | 14.75px | 원본 `(D18.0) 혈관종` 폭 87px에 맞춤 |
| 위치 | x=395, y=405 | 기존 줄 왼쪽 끝, 줄 간격 29px 아래 |
| 잉크 | 20 | 시험 합성으로 획 농도 비교 |
| 번짐 | 0.5px | |
| 기울기 | 0.5도 | 촬영으로 오른쪽이 올라간 행 |

- 마스크: x=394, y=405, w=186, h=16
- `Q82.5`의 정확한 KCD 병명 표기는 확인하지 않았다
