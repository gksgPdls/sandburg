# kcd_swap — 진단서 질병 코드만 바꾸기

주 탐지 축: **콘텐츠 로직** · ID: `CL_xxx` · 스크립트: [`scripts/auto_diag.py`](../../scripts/auto_diag.py) (자동), [`scripts/pick_session.py`](../../scripts/pick_session.py) `kcd_swap` (반자동)

## 조작 방식

진단서의 KCD 질병 코드만 **다른 장(첫 글자)의 코드로** 바꾸고, 병명은 그대로 둔다. 방법론 문서 케이스 4(병명-코드 불일치)이고, 회의에서 예로 든 "비골절인데 골절 코드"가 이 유형이다.

바꿀 코드는 [`kcd_swap_list.csv`](../../kcd_swap_list.csv)에서 고른다. 보험금이 커지는 쪽(골절, 암, 급성 심근경색, 뇌경색)이다. 코드 의미 표기는 KCD 코드표로 확인이 필요하다.

자동(`auto_diag.py`):
1. 진단서 전체를 로컬 OCR로 읽어 `D18.0`, `(D18.0)` 형태의 단어를 찾는다 (신뢰도 70 이상)
2. 괄호를 뺀 코드 부분만 주변 종이로 지우고, 원래 코드의 높이·오른쪽 끝·진하기에 맞춰 새 코드를 쓴다
3. 괄호를 포함한 단어 범위를 다시 읽어 **원래 단어에서 코드만 바뀐 글**이 나올 때만 채택한다

```bash
cd generator/alteration/methods/scripts
../.venv/bin/python auto_diag.py 5 --seed 0
```

진단서는 코드가 작거나 손글씨인 경우가 많아 코드가 읽히는 비율이 낮다(30장 중 2장). 100장을 시도해 5개를 만들었고, 사후 점검에서 다시 읽기가 애매한 1개(CL_026)는 뺐다.

## 탐지 원리

- **콘텐츠 로직:** 병명과 코드가 KCD 코드표와 맞지 않는다. 공개 마스터 대조로 **결정적 판정**이 가능해, 이 데이터셋에서 가장 안정적으로 잡혀야 하는 축이다. 여기서 놓치면 OCR 품질 문제로 봐야 한다
- **글리프:** 다시 쓴 코드의 폰트가 다르다
- **copy-move:** 복사가 없어서 못 잡는다
