# amount_sum_fixed — 금액과 합계를 같이 변경

주 탐지 축: **글리프** · ID: `GL_xxx` · 스크립트: [`scripts/auto_receipt.py`](../../scripts/auto_receipt.py) `sum_fixed`

## 조작 방식

**"항목들의 합 = 합계 칸"이 OCR로 확인된 열**에서 항목 금액 하나와 그 열의 합계를 같은 차이만큼 바꾼다. 방법론 문서의 케이스 2(금액 치환 + 합계 보정)다. 두 칸 모두 지우고 다시 쓴다.

```bash
cd dataset/scripts
../.venv/bin/python auto_receipt.py sum_fixed 5 --seed 0
```

합계 관계가 확인되는 영수증이 적어서(81장 중 3장) 자동으로는 3개만 나왔다. 나머지는 반자동(합계 칸 직접 지정)으로 만든다.

## 탐지 원리

- **글리프:** 주력. 두 곳의 숫자 폰트가 주변 숫자와 다르다
- **콘텐츠 로직:** 이 열의 합계는 맞아서 못 잡는다. 단 진료비 총액·납부액처럼 이 열 합계를 다시 더하는 칸은 고치지 않았으므로 그쪽과는 어긋날 수 있다
