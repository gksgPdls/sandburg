# add_diag — 진단서 병명 칸 여백에 진단 추가 (반자동)

주 탐지 축: **글리프** · ID: `GL_xxx` · 스크립트: [`scripts/pick_session.py`](../../scripts/pick_session.py) `add_diag`

## 조작 방식

진단서의 병명 칸에서 **기존 내용을 지우지 않고 빈 줄에 병명을 한 줄 추가**한다. 실무에서 "정교해서 육안 탐지가 어렵다"고 언급한 실제 수법이다. 진단명이 늘면 보험금이 바로 늘어 사기 동기가 분명하다.

사람이 진단서마다 두 곳을 마우스로 찍고, 나머지는 스크립트가 한다.

1. **기준 줄**(기존 병명 한 줄)을 감싼다. 이 줄에서 글자 높이(획이 많은 행), 진하기(어두운 쪽 5%), 기울기(획 픽셀에 직선을 맞춤, ±3도 제한)를 잰다
2. **새 줄 위치**를 찍는다. 드래그한 네모의 왼쪽 위가 첫 글자 위치다
3. 한글 '가'의 높이가 기준 줄 높이와 같아지는 크기로 병명을 그리고, 같은 기울기로 돌리고, 높이에 비례해 번지게 한다
4. 흰 박스 없이 잉크를 종이에 곱해 합성한다. 진하기는 잉크 값과 획 농도를 여러 가지로 써 보고 기준 줄에 가장 가까운 것을 고른다
5. 결과 화면에서 `t`로 병명, `f`로 표기 형식(`(코드) 병명` / `코드 병명` / `병명 (코드)` / `병명`)을 바꿔 기존 줄과 맞춘다

추가할 병명은 [`kcd_add_list.csv`](../../kcd_add_list.csv)에서 고른다. 코드와 병명이 맞는 흔한 진단(요통, 추간판전위, 염좌, 위염 등)이다. **KCD 공식 표기는 코드표로 확인이 필요하다.**

```bash
cd generator/alteration/methods/scripts
../.venv/bin/python pick_session.py add_diag pick 14   # 찍기 (좌표는 _work/picks/add_diag.json)
../.venv/bin/python pick_session.py add_diag apply     # 찍어 둔 좌표로 다시 만들기
```

폰트는 맥 기본 폰트(Apple SD Gothic Neo)다. 원본 폰트를 구하면 같은 좌표로 apply 만 다시 돌려 더 어려운 변형을 만들 수 있다.

## 탐지 원리

- **글리프:** 주력이자 거의 유일한 축. 추가한 줄의 자형·획 굵기·자간이 기준 줄과 다르다. 크기·진하기·기울기는 맞췄으므로 폰트 차이만 남는다
- **copy-move:** 복사한 픽셀이 없어서 못 잡는다
- **콘텐츠 로직:** 코드와 병명이 맞아 못 잡는다. 추가한 진단이 치료 의견·진료비 영수증과 맞지 않으면 문서 간 대조로 잡을 여지가 있다

## 점검 (자동, 원본 이미지는 VLM 이 보지 않음)

- 새 줄 자리의 원본에 기존 글자 획이 3% 미만 → 기존 글자와 겹치지 않음 (14/14)
- 글자 높이 기준 줄과 1px 이내 (12/14). GL_017, GL_027은 기울기 2~3도라 행 단위 측정값이 커 보인다. 눈으로 확인 필요
- 진하기 기준 줄과 ±5 이내 (14/14)
