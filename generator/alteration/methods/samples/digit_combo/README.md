# digit_combo — 문서 안 숫자를 오려 붙여 금액 바꾸기

주 탐지 축: **copy-move** · ID: `CM_xxx` · 스크립트: [`scripts/auto_receipt.py`](../../scripts/auto_receipt.py) `digit_combo`

## 조작 방식

금액 칸의 **맨 앞자리 숫자를, 같은 문서의 다른 금액 칸에 있는 더 큰 숫자 글자로** 덮는다(예: `150,000` → `250,000`). 새 글자를 그리지 않고 원본 글자를 픽셀째 옮긴다. 방법론 문서의 케이스 8(글리프 이식)이다.

1. OCR 신뢰도가 높은 금액 칸들을 한 줄로 다시 읽어 글자별 위치를 얻는다. 다시 읽은 값이 표 인식 값과 같은 칸만 쓴다
2. 대상 칸의 맨 앞 숫자보다 큰 숫자 글자 중 **획 크기가 비슷한(높이 1px, 폭 2px 이내)** 것을 다른 금액 칸에서 고른다
3. 대상 숫자를 주변 종이로 지우고, 가져온 글자 블록을 오른쪽 끝·윗선에 맞춰 붙인다
4. 대상 칸을 다시 읽어 새 금액이 정확히 나올 때만 채택한다

```bash
cd dataset/scripts
../.venv/bin/python auto_receipt.py digit_combo 5 --seed 0
```

## 탐지 원리

- **copy-move:** 숫자 한 글자 블록이 문서 안 두 곳에 있다. 블록이 아주 작아(글자 하나) 매칭이 어렵다
- **글리프:** 원본 글자를 옮겨서 원리적으로 못 잡는다
- **콘텐츠 로직:** 금액만 바뀌고 합계는 그대로라 합계 불일치로 잡힌다. 합계까지 같은 방식으로 맞추면 copy-move 만 남는 더 어려운 변형이 된다
