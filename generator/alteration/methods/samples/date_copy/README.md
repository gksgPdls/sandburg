# date_copy — 문서 안 다른 날짜의 숫자를 복사해 날짜 바꾸기

주 탐지 축: **copy-move** · ID: `CM_xxx` · 스크립트: [`scripts/auto_receipt.py`](../../scripts/auto_receipt.py) `date_copy`

## 조작 방식

같은 문서에 있는 다른 날짜에서 **일(日) 두 자리를 픽셀째 복사해**, 대상 날짜의 일 두 자리를 덮는다. 새 글자를 그리지 않고 원본 글자를 옮기므로 폰트가 완전히 같다. 방법론 문서의 케이스 8(글리프 이식)이다.

1. 날짜 칸을 찾고 tesseract 글자 위치(makebox)로 각 날짜의 일 두 자리를 찾는다. 범위 안의 실제 획으로 외곽을 다시 잰다
2. 일 숫자가 다르고 **획 크기가 비슷한(높이 1px, 폭 2px 이내)** 두 날짜를 고른다
3. 대상 두 자리를 주변 종이로 지우고, 복사한 블록을 오른쪽 끝·윗선에 맞춰 붙인다
4. 대상 칸을 다시 읽어 새 날짜가 나오고 글자 수가 그대로일 때만 채택한다. 같은 칸의 시작~끝 순서가 뒤집히는 경우는 `date_conflict`와 겹쳐서 뺀다

**외래 영수증은 진료기간이 하루짜리(`03.10 ~ 03.10`)라 일이 다른 날짜 짝이 거의 없다**(663장 중 2개). 그런 짝이 없으면 **끝 날짜 일의 끝자리 한 글자**를 문서 안 다른 숫자 글자(날짜·금액 칸)로 덮어 날짜를 뒤로 미룬다(예: `03.10` → `03.13`). 기간이 늘어 보험금이 늘어나는 방향이다. CM_016~017은 두 자리, CM_018~020은 끝자리 한 글자 방식이다.

```bash
cd generator/alteration/methods/scripts
../.venv/bin/python auto_receipt.py date_copy 5 --pool ../_work/pool/DOC210 ../_work/pool/DOC205 --seed 0
```

## 탐지 원리

- **copy-move:** 같은 두 숫자 블록이 문서 안 두 곳에 있다. 블록이 작아(숫자 두 개) 일반적인 copy-move 블록 크기보다 작을 수 있어 난이도가 있다
- **글리프:** 원본 글자를 그대로 옮겨서 원리적으로 못 잡는다
- 글리프를 피한 대가로 copy-move 에 노출되는 구조라, **두 엔진을 함께 걸어야 잡히는** 케이스다
