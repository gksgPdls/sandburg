# copymove — 문서 내 복사·붙여넣기

주 탐지 축: **copy-move** · ID: `CM_xxx` · 스크립트: [`scripts/tamper_copymove.py`](../../scripts/tamper_copymove.py)

## 조작 방식

문서 안의 한 영역(금액, 날짜, 도장 등)을 잘라 **같은 문서의 다른 위치에 픽셀 그대로** 붙인다. 생성형 AI는 쓰지 않는다. AI는 픽셀을 새로 만들어 내므로 카피무브가 되지 않는다.

1. 복사할 영역과 붙일 위치를 정한다. 표 안이라면 괘선(종이보다 어두운 행·열)의 위치를 재서 **괘선 안쪽만** 잡는다. 괘선까지 옮기면 선이 두 줄로 겹친다
2. 스크립트로 붙이고, 붙인 좌표로 정답 마스크를 바로 만든다

```bash
cd dataset
./.venv/bin/python scripts/tamper_copymove.py samples/copymove/CM_001_original.jpg \
    --src-box X Y W H --dst X Y \
    -o samples/copymove/CM_001_tampered.jpg --mask samples/copymove/CM_001_mask.png
```

좌표 대신 `--pick`을 주면 창이 떠서 마우스로 고를 수 있다(복사할 영역 드래그 → ENTER → 붙일 위치 드래그 → ENTER).

## 자동 생성 (CM_002~)

[`scripts/auto_receipt.py`](../../scripts/auto_receipt.py) `copymove`가 좌표 찾기까지 자동으로 한다.

1. 괘선으로 표의 칸을 나누고, 로컬 OCR(tesseract)로 칸별 숫자를 읽는다 (문서 내용은 출력하지 않는다)
2. 같은 열에서 금액 칸(1,000 이상, OCR 신뢰도 85 이상)과 `0` 칸 또는 빈칸을 고른다. 두 칸의 크기가 2px 안쪽으로 같아야 한다
3. 괘선 안쪽만 복사해 붙이고, 조작 전후에 바뀐 픽셀로 마스크를 만든다

```bash
cd generator/alteration/methods/scripts
../.venv/bin/python auto_receipt.py copymove 9 --seed 0
```

원본은 `sample_originals.py`로 `real_docs`의 DOC210(진료비 영수증)에서 무작위로 뽑는다. 가로 사진은 세로로 돌려 처리하고 되돌린다.

## 탐지 원리

- **copy-move:** 같은 픽셀 블록이 문서 안에 두 번 나온다. 블록 매칭이나 특징점 매칭으로 영역 쌍을 찾는다. 이 폴더의 샘플은 전부 잡혀야 한다(회귀 기준선)
- **글리프:** 원래 있던 글자를 옮기므로 폰트·자간이 같아서 원리적으로 못 잡는다
- **콘텐츠 로직:** 금액을 옮기고 합계를 고치지 않으면 합계 불일치로 잡힌다. copy-move만 따로 시험하려면 합계까지 맞춘다

## 원본 선정 기준

- 전자문서(디지털 원본 PDF)는 제외한다. 같은 글자의 픽셀이 원래 똑같아서 정상 문서도 copy-move에 걸린다
- 촬영본·스캔본을 쓴다

## 샘플

### CM_001 — 비급여 금액 셀 복제 (영수증)

치료재료대 행의 비급여(선택진료료 이외) 셀 `150,000`을 복사해 같은 열의 **MRI 진단료** 행(원래 `0`)에 붙였다. 비급여 MRI 150,000원을 청구에 끼워 넣는 형태다.

| | x | y | w | h |
|---|---|---|---|---|
| 복사한 영역 | 644 | 558 | 84 | 18 |
| 붙인 영역 (= 마스크) | 644 | 673 | 84 | 18 |

- 괘선 위치: 원본 셀 가로선 y=556·578, MRI 셀 가로선 y=671·692, 세로선 x=642·729 (두 셀 같음)
- 합계 행(비급여 280,000)은 고치지 않았다. 비급여 항목 합이 430,000이 되어 콘텐츠 로직에도 걸린다
- JPEG로 다시 저장한 뒤에도 복사한 곳과 붙인 곳의 평균 픽셀 차이는 1.24(0~255)다
- 마스크에는 붙인 영역만 칠했다. 복사해 온 영역도 칠할지는 추가 확인이 필요하다
