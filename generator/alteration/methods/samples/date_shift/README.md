# date_shift — 날짜의 일(日) 바꾸기

주 탐지 축: **글리프** · ID: `GL_xxx` · 스크립트: [`scripts/auto_receipt.py`](../../scripts/auto_receipt.py) `date_shift`

## 조작 방식

진료비 영수증의 날짜 칸(진료기간 등)에서 **일(日) 두 자리만** 지우고 다른 날로 다시 쓴다(±1~3일). 한 칸에 날짜가 두 개(시작~끝)면 둘 다 같은 만큼 바꿔 순서를 유지한다. 연·월과 구분 기호는 원본 픽셀 그대로다.

1. 넓은 칸까지 표를 읽어 날짜 칸을 찾는다
2. 날짜 칸을 한 줄로 다시 읽어 tesseract 가 주는 글자별 위치(makebox)를 얻고, 일 두 자리의 범위 안에서 실제 획으로 위치·높이를 다시 잰다
3. 두 글자를 주변 종이로 지우고, 같은 높이·오른쪽 끝·진하기로 새 두 자리를 쓴다
4. **그 칸을 다시 읽어 새 날짜가 나오고 글자 수가 그대로일 때만 채택한다.** 옆 글자를 지웠거나 숫자가 뭉개졌으면 되돌린다

구분 기호(`-` `.`)가 있는 날짜와, 앞뒤가 숫자가 아닌 정확히 8자리 날짜만 쓴다. 두 날짜가 붙어 16자리로 읽히는 경우는 일의 위치가 모호해서 뺀다.

```bash
cd generator/alteration/methods/scripts
../.venv/bin/python auto_receipt.py date_shift 10 --pool ../_work/pool/DOC210 ../_work/pool/DOC205 --seed 0
```

## 탐지 원리

- **글리프:** 주력. 같은 칸 안에서 연·월 숫자는 원본이고 일 두 자리만 다른 폰트다. 가장 좁은 범위의 글리프 불일치라 난이도가 있다
- **콘텐츠 로직:** 칸 안의 날짜 순서는 유지해서 약하다. 발행일이나 다른 서류의 날짜와 대조하면 어긋날 수 있다
- **copy-move:** 복사가 없어서 못 잡는다
