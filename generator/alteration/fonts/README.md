# fonts/ (글꼴 파일은 git에 올리지 않음)

4단계(폰트 맞추기)에서 쓸 윈도우 글꼴 파일을 이 폴더에 넣는다. 이 폴더의 글꼴 파일은 .gitignore로 제외된다.

넣을 파일 (윈도우 C:\Windows\Fonts 에서)
- gulim.ttc   굴림, 굴림체, 돋움, 돋움체
- batang.ttc  바탕, 바탕체
- malgun.ttf, malgunbd.ttf, malgunsl.ttf  맑은 고딕

Arial, Times New Roman, Courier New는 맥에 이미 있어서 필요 없다.
확인: 저장소 최상위의 글꼴확인.command 실행 -> outputs/고도화/글꼴후보.txt 에 위 글꼴이 보이면 된다.
